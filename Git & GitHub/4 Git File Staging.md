#### ايه اللي بيحصل فعليا في ال [ Staging Area ]

نتخيل ان في فايل لسه معملول و لسه مخدناش ليه اي version جديده , و لا اي snapshot 
هنا بيبقي [ Untracked ] فلازم الاول اعرف Git انه [ Tracked ] , و بعمل كده من خلال امر 
[ add ] 
و هنا ال staging area بتبدا بدخل ال blob دا علي [ Hashing function ] -----> [ SHA-1 ]
عشان يديلو ID , و يعرف يعمله tracking 

, بعد كده يبقي في الخباثة ال Staging Area بتروح لل Git tree بتعمل للفايل دا Blob جديد 
و دا مش معناه انه كده اتعمله Commit او بقي في version جديده منه 

عشان بقي يبقي في version جديده بشكل فعلي بكتب امر [ commit ]
