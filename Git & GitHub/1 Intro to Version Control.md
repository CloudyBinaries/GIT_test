

## **مقدمة بسيطة وسهلة عن Version Control**

تخيّل عندك دفتر كبير، كل صفحة فيه نسخة مختلفة من مشروعك.  
مرة تصلّح سطر، مرة تجرب فكرة، مرة تخرب كل حاجة بالغلط… ومع ذلك عندك زر يرجّعك لأي صفحة قديمة من غير ما تتوه.

**ده بالضبط اللي بيعمله الـ Version Control.**

هو نظام بيحفظ تاريخ كل تعديل في مشروعك — ملف… سطر… فكرة — وكأنه سجلّ زمن صغير يمشي جنبك، يدوّن كل حركة من غير ما يشتكي.

---

## ليه بنستخدمه؟

- **الرجوع بالزمن**: غلطت؟ عملت كارثة؟ النظام بيقولك: "ولا يهمك، رجّعتك للِّي قبله".
    
- **متابعة الشغل**: تعرف مين عمل إيه ومتى، بكلمات قصيرة ومعبرة.
    
- **التجارب الآمنة**: تقدر تفتح فرع (branch) كأنك بتجرب فكرة على ورق جانبي، وبعدها تقرر تضمها أو تمزّقها.
    
- **شغل الفريق**: بدل ما الملفات تتصادم زي عربيات في شارع ضيق، النظام يرتّب كل تغيّر ويساعد الناس تشتغل من غير لخبطة.
    

---

## أشهر مثال: Git

أكتر نظام منتشر… زي لغة السرّ بين المطورين.  
Git بيخلّي جهازك يحتفظ بكل تاريخ مشروعك، وبعدها تقدر ترفعه على خدمات زي GitHub علشان تشتغل من أي مكان وتتعامل مع الفريق لو موجود.
